# Mundo Cable Visión

Sitio web de Mundo Cable Visión, empresa de TV por cable, internet por fibra óptica, LTE y microondas rural en Mariscala y zonas rurales de Lavalleja, Uruguay.

**Ver el sitio:** https://luciaaherr.github.io/mundo-cable-vision/

## Estructura

```
index.html     página principal
css/style.css  estilos
js/script.js   interacciones (menú, etc.)
img/           fotos e imágenes del sitio
```

## Cómo verlo en local

Abrir `index.html` directamente en el navegador, o levantar un servidor simple:

```
python3 -m http.server
```

y entrar a `http://localhost:8000`.
